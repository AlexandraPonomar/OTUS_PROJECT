# Прогнозирование личностных черт Big Five по тексту резюме методами машинного обучения»

## Цель проекта:
<br>
Разработать модель машинного обучения, которая по тексту резюме предсказывает выраженность пяти базовых черт личности (Открытость, Добросовестность, Экстраверсия, Доброжелательность, Эмоциональная стабильность) в рамках психометрической модели «Большая пятёрка» (Big Five / OCEAN).
<br>

## Задачи проекта:
<br>
Изучить и подготовить датасет HYPskill, содержащий предложения из резюме, размеченные экспертами-психологами по модели Big Five.

Провести разведочный анализ данных (EDA): оценить распределение классов, длину текстов, дисбаланс по каждой черте.

Выполнить предобработку текста: токенизация, лемматизация, удаление стоп-слов.

Построить и обучить baseline-модели: TF-IDF + Logistic Regression, Random Forest для того чтобы сравнить их работу.

Провести гиперпараметрическую настройку и выбрать лучшую модель.

Проанализировать ошибки модели по каждой черте, сопоставить результаты с литературой.

Разработать простой демонстрационный интерфейс, принимающий текст резюме и выдающий оценки по пяти чертам.

Оформить отчёт с описанием методологии, результатов, ограничений и выводов.
<br>
## Планируемый результат:
<br>
Обученная ML-модель, предсказывающая выраженность пяти черт Big Five по тексту резюме, с метриками (F1-score, Precision, Recall) по каждой черте.

Сравнение эффективности нескольких алгоритмов.

Демонстрационный веб-интерфейс на Streamlit для ввода текста и получения оценки.

Отчёт с интерпретацией результатов и ограничений (например, какие черты предсказываются лучше/хуже и почему).

Сохранённые артефакты для воспроизводимости.

Инструменты / технологии:

Язык: Python 3.11+

Библиотеки ML: scikit-learn (TF-IDF, LogisticRegression, RandomForest, GridSearchCV, Pipeline)

Обработка данных: pandas, numpy

Обработка текста: nltk

Визуализация: matplotlib, seaborn

Демо-интерфейс: Streamlit

Сохранение модели: joblib

Данные: HYPskill Dataset (Kaggle)
